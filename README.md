# RAG Multi-Mode System

A Streamlit-based Retrieval-Augmented Generation (RAG) system with dual-mode querying and document context parsing.

## Features
- Direct PDF and DOCX document ingestion
- ChromaDB vector store integration
- Dual-mode processing (Standard QA & Style Mimicking)
